# 开发计划与 Agent 协作

Codex 负责确定里程碑、拆分任务、维护跨端契约、协调依赖与改动范围，并按任务卡验收。其他 Agent 可以独立认领任务、实现和验证，通过看板和任务卡交接。

## 领取任务

前端开发与修复任务只由 **Antigravity App** 领取和实现。跨端联调发现的前端改动，由 Codex 交给 Antigravity App 处理。

1. 阅读项目协作规范、当前里程碑和任务卡。涉及流程细节时核对 PRD 和静态原型，开始实现前查阅卡片指定的本地 Skills。 [项目协作规范](../../AGENTS.md) · [PRD](../../PRD.md) · [静态原型](../../static/index.html)
2. 在看板选一张「待领取」的任务卡，核对「领取资格」和所有前置任务的完成状态。填写承接 Agent、工作分支或工作树、更新时间，将状态改为「进行中」。每张卡登记一位交付负责人。
3. 同一工作区以看板中的登记为准。多分支并行时，从团队共享分支核对看板，先同步认领记录，或由 Codex 统一登记后开工。若同一任务出现两个认领，以先登记到共享看板的记录为准，另一位 Agent 改领其他任务。 [任务看板](board.md)

## 实施、交付与验收

- 按卡片约定的文件范围实施。发现共享契约、迁移顺序或公共入口需要变更时，在卡片写明影响范围，由 Codex 协调归属和合并顺序。遇到无法继续的依赖时，将状态改为「阻塞」，记录原因及恢复条件。
- 交付时在卡片的「交付记录」填写变更文件、提交或 PR、执行过的验证及其结果、尚未验证的场景。将看板状态改为「待验收」，附上交付引用。
- Codex 按卡片逐项验收，记录结论。验收通过且交付已纳入共享基线后，标为「已完成」，并把满足依赖的任务移为「待领取」。需要补改时退回「进行中」，在卡片记录具体差项。

任务状态与认领只维护在看板，任务卡保存范围、验收标准和执行证据。调整优先级或拆分任务时，Codex 同步更新看板和依赖。 [任务看板](board.md)
