# T004 对练、评分及复练回写

前置任务为 T002。可用同契约的已发布课程测试数据与 T003、T005 并行。 [任务看板](../board.md)

## 目标与范围

负责 `backend/` 中对练、评分模块及其测试。用 LangGraph `StateGraph` 编排文字对练和结构化评分证据，按 MySQL 中已保存的轮次恢复。业务层计算正式成绩并负责复练时的自动状态推进，店长指派和复查由 T005 实现。查阅 `langchain-build-agent`、`fastapi`、`sqlalchemy`、`mysql-patterns`。 [项目 Skills](../../../.agents/skills/README.md)

## 交付与验收

- [ ] 创建会话时校验参与人和发布批次，绑定已发布的课程和评分规则版本。轮次顺序与重试结果在刷新或服务重启后可恢复。
- [ ] 提供可重复的模型替身和「端盒 6 个不重复」样本，覆盖正确、同义表达、漏讲、事实错误。业务层按绑定规则核验命中、缺失和证据，产出可解释成绩。
- [ ] 模型调用在事务外。核验后在同一短事务内写正式成绩及复练结果。重复提交返回同一份成绩，并发轮次按契约有序写入或返回冲突，过期结果不会覆盖当前补训状态。
- [ ] 为漏讲保留补训待办，改正后推进至待复查。模型调用失败或输出无效时保留已保存轮次，允许重试，且不产生正式成绩。
