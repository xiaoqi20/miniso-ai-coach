# T003 审校发布与员工学习 API

前置任务为 T002。 [任务看板](../board.md)

## 目标与范围

负责 `backend/` 中课程与学习模块及其测试。实现总部录入或使用种子草稿、人工审校、不可变课程版本克隆、门店定向发布，以及员工课程列表、详情和进度。提供其他业务模块可使用的已发布课程版本和应训数据。查阅 `fastapi`、`sqlalchemy`、`mysql-patterns`。 [项目 Skills](../../../.agents/skills/README.md)

## 交付与验收

- [ ] 总部完成审校才能发布。发布写入课程与规则版本、服务端发布时间、目标门店及应训名单，后续改稿和成员变更不回写旧批次。
- [ ] 可从已冻结版本克隆新草稿及独立评分规则；版本号并发生成唯一，旧版本和已发布批次保持可追溯。已替代的旧版本不能新建发布。
- [ ] 门店 A 员工可读面向本店且分配给本人的已发布课程，门店 B 员工不能看到该课程。直接访问详情和写入进度时同样校验身份与范围。
- [ ] 员工学习进度按契约保存，重复上报同一章节后进度保持一致。读取草稿、越权和非法进度请求返回契约规定的结果。
- [ ] 使用试点开发数据验证审校、发布、读取及续学，记录接口示例，供前端和闭环验收使用。
