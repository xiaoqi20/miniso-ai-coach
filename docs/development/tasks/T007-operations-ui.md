## 交付与验收

- [ ] 总部 PC 页能查看及审校新品草稿、核对目标门店和截止时间、提交发布并查看结果。
- [ ] 店长 H5 能查看授权店员的培训进度、48 小时统计与卡点，可指派补训、查看复练证据、确认待复查结果。
- [ ] 权限失败、重复提交及状态冲突有可理解的反馈。用桌面视口和移动视口走通各自路径，记录结果供 T008 联调使用。
